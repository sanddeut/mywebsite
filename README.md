# 연구잇다

대학원생 연구자와 연구 참여자를 이어주는 모집·매칭 플랫폼이에요.

- **연구 찾기**: 설문·인터뷰·실험·뇌영상 등 모집 중인 연구를 전단처럼 모아 보여줘요. 나이·성별·지역을 넣으면 참여할 수 있는 연구에 「조건 맞음」이 붙고, 안 맞으면 이유를 알려줘요. 유형·검색·정렬(마감 임박, 시간당 사례비, 짧은 연구, 최신 등록)도 할 수 있어요.
- **참여 신청**: 연구를 누르면 사례비, 소요 시간, 장소, IRB 승인번호를 보여줘요. 참여 조건을 하나씩 확인한 뒤 이름과 연락처를 남겨 신청해요.
- **연구 등록**: 연구자가 연구 정보, 모집 조건, IRB 승인번호, 마감일을 입력해 공고를 올려요.
- **내 활동**: 신청한 연구와 올린 공고, 공고별 신청자 목록을 봐요.

## 지금 상태 (체험판)

서버 없이 정적 파일로만 만든 화면이에요. 등록한 공고와 신청 내용은 **그 사람의 브라우저(localStorage)에만** 저장돼서, 다른 사람에게 보이거나 연구자에게 전달되지는 않아요. 실제로 운영하려면 데이터베이스와 로그인(예: Supabase, Firebase)을 붙여야 해요.

## 실행

```bash
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000
```

## GitHub Pages로 공개하기

저장소 **Settings → Pages**에서 Source를 `Deploy from a branch`, Branch를 `main` / `/(root)`로 저장하면 `https://sanddeut.github.io/mywebsite/`에서 열려요.

## 파일

| 파일 | 내용 |
|---|---|
| `index.html` | 화면 구조 (연구 찾기 / 연구 등록 / 내 활동) |
| `css/style.css` | 디자인 |
| `js/data.js` | 예시 연구 공고 9건, 지역·유형 목록 |
| `js/app.js` | 매칭, 필터, 신청, 등록 동작 |

## 수정할 때 주의

`css/style.css`나 `js/*.js`를 바꾸면 `index.html`에서 그 파일 주소 끝의 `?v=숫자`를 하나 올려 주세요. 그래야 휴대폰 브라우저가 예전 파일을 쓰지 않고 새 파일을 받아요.
